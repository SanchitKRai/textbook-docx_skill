## The cell cycle

The cell cycle includes interphase and M phase. Cell cycle progression is regulated by cyclins and cyclin-dependent kinases.

### Regulation

The checkpoint system coordinates DNA replication and chromosome segregation.

- G1 phase
- S phase
- G2 phase
- M phase

```python
# Estimate a population after n doublings
initial_cells = 100
number_of_doublings = 3
final_cells = initial_cells * (2 ** number_of_doublings)
print(final_cells)
```

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
